POKÉMON CREATOR v0.2 · READ ONLY + ANALYZER

🔎 POKÉMON ID SCANNER

ขั้นแรกของ Pokémon Creator: ตรวจหา Species ID ที่มี slot ว่างใน ROM โดยยังไม่เขียนหรือแก้ไข ROM ใด ๆ

iPhone/iPad: หากไฟล์ .gba เป็นสีจาง ให้ใช้ตัวเลือก “Browse/เลือกหา” แล้วแตะไฟล์โดยตรง ระบบจะตรวจนามสกุลภายหลัง
เลือกไฟล์ ROM ก่อนเริ่มสแกน

📋 ผลการตรวจสอบ

🟢 EMPTY = record เป็นศูนย์ทั้งหมด 🟡 UNKNOWN = มีข้อมูล แต่ยังยืนยันไม่ได้ 🔵 USED = มีข้อมูล

🧬 POKÉMON ID ANALYZER v0.2

วิเคราะห์ช่อง ID แบบ Read Only เพิ่มจาก Scanner โดยตรวจ Primary Record, pointer ที่เกี่ยวข้อง และตาราง Special Handler ที่เรารู้ตำแหน่งจาก ROM นี้ ผลลัพธ์เป็น “Candidate” ไม่ใช่การรับรองว่าสามารถเพิ่ม Pokémon ได้ทันที

เลือก ROM และกด SCAN ROM ก่อน

⚠️ ขอบเขต v0.2

เครื่องมือนี้เป็น Read Only เท่านั้น
ยังไม่มีการสร้าง Pokémon, เปลี่ยน pointer, เขียน graphics หรือบันทึก ROM
คำว่า EMPTY หมายถึง record 0x118 bytes ในตารางหลักของ PKSG เป็นศูนย์ทั้งหมดเท่านั้น Analyzer จะเพิ่มการตรวจ pointer/reference ที่รู้ตำแหน่งแล้ว แต่ยังไม่เขียน ROM และยังไม่ถือว่าเป็น “ปลอดภัย 100%”
